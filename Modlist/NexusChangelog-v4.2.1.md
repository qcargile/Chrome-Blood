## 🛠 Key Notes

- **Unified Mod Settings Profiles Repaired**\
  The Standard and Immersive profiles have been rebuilt and verified through clean Overwrite tests. Shared mods now carry the intended saved settings and browser organization in both profiles, while Immersive-only settings remain separate. Please continue reporting any setting that does not match the included profile.
- **⚠️ Back Up v4.2 Saves and Personal Settings Before Updating**\
  Follow the [FAQ backup instructions](https://qcargile.github.io/Chrome-Blood/faq.html#backups-updates) before installing this hotfix. Back up the profile-specific saves you use and any personal settings stored in Overwrite so changes you made individually on v4.2 can be restored after the corrected profiles are installed.
- **Kiroshi Optics Vision Stack Expanded**\
  The existing **[Kiroshi Optics Night Vision Mod](https://www.nexusmods.com/cyberpunk2077/mods/8326)** now pairs with the new **[Kiroshi Optics Thermal Vision](https://www.nexusmods.com/cyberpunk2077/mods/32729)**, giving supported Kiroshi optics dedicated night-vision and three-mode thermal options through one compatible vision stack.
