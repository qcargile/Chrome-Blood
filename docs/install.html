// SETUP PROTOCOL

Installation

Follow the steps in order. Most install problems come from skipping the preinstallation list.

Read first: The current public release targets Cyberpunk 2077 2.31a on Steam and requires the Phantom Liberty DLC and an official copy of the game. A newer game patch is not automatically supported. An SSD is required — do not try to run this on an HDD. Only Windows 10/11 is supported.

Setup 1.0.1: The setup tool targets Cyberpunk 2077 2.5 and preserves verified DLSS swaps and their backups. Use it with a C&B revision that supports that version. Publishing the tools does not update the modlist; the current public list's version requirements above still apply. The release includes SHA-256 checksums and MIT-licensed source.

01 · SYSTEM REQUIREMENTS

System Requirements

Based on internal testing and community feedback. Your mileage will vary depending on hardware, background programs, and drivers.

~84.6 GBVanilla Game + DLC
~11 GBModlist Download
~9.6 GBModlist On Disk
~105 GBTotal (Game + List)

The modlist itself is only ~9.6 GB on disk — the rest is the ~84.6 GB vanilla game it sits on top of, for ~105 GB total. Have at least 160 GB free on the SSD before you start; the install needs working room while Wabbajack downloads and extracts.

02 · SETUP TOOL

The Easy Way: Run the Setup Tool

Chrome & Blood Setup finds your game, selects missing Windows components and Wabbajack, and offers cleanup with retained backups. Optional resets and Steam preferences stay separate. It finishes by opening the C&B listing in Wabbajack. For older 2.31a list revisions, use the matching manual instructions below.

Download Setup 1.0.1 for 2.5 View the Source
  1. Extract and run ChromeBloodSetup.exe

    Keep the extracted Assets and licenses folders with it. Setup runs without administrator rights; Windows asks when a selected step needs elevation.

  2. Check the selected game and preparation

    Choose the right copy if more than one is found. Missing components are selected; optional actions start off. Game cleanup and verification are shown prominently.

  3. Review and prepare

    Close the game and mod managers before cleanup, and close Steam when cleaning its game folder. Files removed by cleanup stay backed up. Official files that need repair are left for the game store to repair.

  4. Open C&B in Wabbajack

    Sign in to Nexus and choose the installation and downloads folders there. Wabbajack handles the list installation. Once it finishes, launch through the installed ModOrganizer.exe.

Download from the linked GitHub release. Setup is unsigned, so Windows may show an unknown-publisher warning. The release includes SHA-256 checksums to identify the exact files. A matching checksum is not a malware scan; investigate security alerts rather than assuming they are false positives.

The source is public under MIT, with third-party licenses retained. Setup downloads prerequisites from Microsoft and Wabbajack's official release, verifies their publishers, and keeps removed game files in backups. It requires no Nexus credentials and has no telemetry.

03 · BY HAND

Prefer to Do It Yourself?

Everything the tool automates, by hand, all the way to launch. You only need this if you skipped the tool, so don't do both. Instructions assume the Steam version of the game.

Show the full manual setup
  1. Perform a clean install of Cyberpunk 2077

    No mods or leftover files, using the exact game version required by your C&B revision. A newer patch is not automatically compatible. Install it outside of Program Files.

  2. Keep cloud sync away from the install

    Do not put the game, the modlist, or the downloads folder anywhere OneDrive, Dropbox, or any other sync service touches. Synced folders lock files mid-install and break MO2's virtual file system.

  3. Install the Visual C++ Redistributables (All-in-One)

    Extract and run install_all.bat.

  4. Disable Steam auto-updates
    • Right-click Cyberpunk 2077 in your Steam Library → Properties
    • Go to the Updates tab
    • Set Automatic Updates to "Only update this game when I launch it"
    • From now on, only launch the game through Mod Organizer 2
  5. Make sure all official DLC is installed
  6. Install REDmod

    It's a free DLC on Steam — Steam must show both Cyberpunk 2077: REDmod and Cyberpunk 2077: Phantom Liberty as installed.

  7. Update your GPU drivers

    NVIDIA App or AMD Adrenalin.

  8. Install the .NET Runtime (latest version)
  9. Install the DirectX End-User Runtime

Then install the list with Wabbajack:

  1. Download Wabbajack

    Put it somewhere safe — not inside your Cyberpunk folder and not in a protected location like Program Files. Example: D:\Wabbajack

  2. Open Browse Modlists, filter by Cyberpunk 2077, and find Chrome & Blood

    Tick Featured, or search the name if it doesn't show right away. You can also reach it from the Nexus Collection or Nexus page — both route into Wabbajack.

  3. Set your paths
    • Installation: D:\Wabbajack\Chrome & Blood
    • Downloads: D:\Wabbajack\downloads — a shared downloads folder lets different Wabbajack lists reuse the same archives
    • Both folders need to be on the same drive as your Cyberpunk install, and not inside the game directory or Program Files
  4. Hit Install

    Let Wabbajack run — don't interrupt it; it can take a while depending on your connection and hardware. Running third-party antivirus? Set your exclusions first (see Antivirus below).

  5. Open the install folder and launch ModOrganizer.exe

    Head to First Launch below.

04 · ANTIVIRUS

Antivirus

Third-party antivirus breaks this list. Software like BitDefender, Norton, and Webroot fights MO2's virtual file system and can quarantine files mid-install. Add your install and downloads folders to its exclusions before you install, or remove it entirely for this list. Windows Defender with smart browsing habits is enough.

How to add a Windows Defender exclusion
  1. Open Windows Security
  2. Go to Virus & threat protection
  3. Click Manage settings
  4. Scroll to Exclusions → Add or remove exclusions
  5. Add your Chrome & Blood installation folder
  6. (Optional) Also exclude ModOrganizer.exe and Cyberpunk2077.exe
05 · FIRST LAUNCH

First Launch

  • Pick your profile — Immersive or Standard — in MO2, then hit Run. Never launch Cyberpunk directly through Steam or a desktop shortcut.
  • Press Numpad 0 to open Unified Mod Settings. Its categories are organized by the part of the game you want to change. Adding, removing, or reordering mods is different and falls under Rule 11.
  • Press H to open the Character menu, then select Database. The first category contains the Chrome & Blood Player Guide, including current controls and profile-specific instructions.
  • Performance not ideal? The FAQ's Graphics & Performance section has the full step-by-step setup.
06 · UPDATING

Updating the Modlist

  1. Open Wabbajack and find Chrome & Blood

    The gallery listing always points to the latest version — there's no separate file to download.

  2. Point it at the same install folder you used before

    Use the exact same installation path. Wabbajack overwrites the old version with the current one — nothing to tick, no boxes to check.

  3. Install, then launch through Mod Organizer 2

Back up first: saves and personal settings live in your profile folder. The FAQ covers exactly what to back up before an update, and how to keep your own added mods safe with the [NoDelete] tag.
